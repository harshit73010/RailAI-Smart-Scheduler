# RailAI-Smart-Scheduler
RailAI Smart Scheduler is an interactive web-based train management system built using Streamlit and Python. It simulates a simplified version of railway scheduling platforms like IRCTC, allowing users to explore, search, and manage train schedules efficiently.

🌟 Features

🚆 View All Trains
Display complete train schedule in a structured table.
🔍 Search Train (Source → Destination)
Find trains between two cities instantly.
🔎 Search by Train Number
Locate a specific train using its unique number.
➕ Add Train
Dynamically add new train records to the system.
❌ Delete Train
Remove train entries easily.
⏰ Sort Trains
Sort trains based on departure time.

🎯 Project Objective

The goal of this project is to:

Demonstrate CRUD operations using Streamlit
Build a real-time interactive UI
Simulate a railway scheduling system
Practice data handling using Pandas
🛠️ Tech Stack
Frontend & Backend: Streamlit
Language: Python
Data Handling: Pandas
